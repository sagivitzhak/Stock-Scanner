# לוח קטליזטורים – מניות ארה״ב

לוח של דוחות רבעוניים, החלטות FDA והחלטות ריבית של הפד. הוא מתעדכן אוטומטית בכל יום מסחר דרך GitHub Actions.

## איך זה עובד
| קובץ | מה הוא עושה |
|---|---|
| `index.html` | הדשבורד. טוען את `data.js` |
| `catalysts.json` | **הקובץ שעורכים ידנית**: רשימת המעקב, אירועים, ניתוחים ומקורות |
| `update_data.py` | מושך נתונים חיים ומייצר את `data.js` |
| `data.js` | נוצר אוטומטית. לא עורכים אותו |
| `.github/workflows/update.yml` | מריץ את הסקריפט בימים א׳–ה׳ ב-14:00 שעון ישראל (15:00 בשעון קיץ), ושומר את השינויים |

### מה מתעדכן לבד
- **Yahoo Finance (`yfinance`)**: תאריך הדוח הבא, קונצנזוס EPS והכנסות, מחיר, שווי שוק, מכפילים, יעד אנליסטים והמלצה. זה נעשה לכל מניה ב-`watchlist`. מניה עם דוח ב-75 הימים הקרובים מקבלת כרטיס אוטומטי.
- **FOMC**: תאריכי החלטות הריבית עד נובמבר 2027, לפי הלוח המעודכן של הפד מ-12.11.2026. צריך לעדכן אותם פעם בשנה, בראש `update_data.py`.
- **openFDA**: אחרי שתאריך החלטה עובר, הסקריפט בודק אם מופיע אישור. אם הוא מוצא אחד, הכרטיס מסומן "אושר".
- אירועים שעברו לפני יותר מ-21 יום יורדים מהלוח.

### מה עדיין ידני
- **תאריכי PDUFA עתידיים.** אין להם מקור רשמי חינמי, ו-openFDA מכיל רק אישורים שכבר ניתנו. מוסיפים אותם ב-`catalysts.json`.
- **הניתוח הכתוב**, כלומר השדות `ev`, `b` ו-`m`.

## תוספות
- **תנועה צפויה (Expected Move):** לכל אירוע ב-45 הימים הקרובים הסקריפט מחשב סטראדל ATM לפקיעה הראשונה אחרי האירוע, באחוזים מהמחיר. החישוב כולל את כל הימים עד הפקיעה, ולכן זה גבול עליון גס לתנועה סביב האירוע עצמו.
- **התראות בבוקר:** `notify.py` רץ כל יום ב-09:00 שעון ישראל (10:00 בשעון קיץ), דרך `.github/workflows/notify.yml`. הוא שולח את האירועים של היום ומחר, רק למניות שברשימה `alerts` ב-`catalysts.json`.
  - טלגרם: יוצרים בוט אצל ‎@BotFather ושולחים לבוט הודעה. את ה-chat id מקבלים מ-`https://api.telegram.org/bot<TOKEN>/getUpdates`. אחר כך מוסיפים את הסודות `TELEGRAM_BOT_TOKEN` ו-`TELEGRAM_CHAT_ID`.
  - מייל (לא חובה): מוסיפים את הסודות `SMTP_HOST` (למשל smtp.gmail.com), `SMTP_USER`, `SMTP_PASS` (סיסמת אפליקציה של Gmail) ו-`ALERT_EMAIL`.
- **סנכרון בין מכשירים:** רשימת `alerts` נשמרת ב-repo. כל מניה שבה מסומנת ב-🔔 ובכוכב בכל מכשיר, וזו גם הרשימה שמקבלת התראות. כוכב שמסמנים בדפדפן נשאר מקומי.
- **סיכום AI:** אם מוסיפים את הסוד `ANTHROPIC_API_KEY`, כל כרטיס בלי ניתוח ידני מקבל משפט ציפיות ו-3 נקודות לבדיקה. הם נכתבים רק מהנתונים שנמשכו, ונשמרים ב-`ai_cache.json`, כך שכל כרטיס עולה קריאה אחת בלבד.

הסודות מוגדרים ב-Settings ← Secrets and variables ← Actions ← New repository secret.

## פעולות נפוצות
- **להוסיף מניה למעקב:** מוסיפים את הסימבול ל-`watchlist` ב-`catalysts.json`.
- **להריץ עדכון עכשיו:** בלשונית Actions בוחרים Update dashboard data ← Run workflow.
- **להריץ על המחשב:** `pip install yfinance` ואז `python update_data.py`. אפשר גם להריץ `python update_data.py --offline` כדי לבנות מחדש בלי רשת.

## הסתייגויות
`yfinance` היא ספרייה לא רשמית. Yahoo חוסם לפעמים שרתי ענן או משנה שדות. אם משיכה נכשלת, הסקריפט שומר את הנתונים מהריצה הקודמת ולא מוחק אותם. זה אינו ייעוץ השקעות.
